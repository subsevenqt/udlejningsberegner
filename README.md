# Udlejningsberegneren

Gratis beregner til private udlejere i Danmark: cash flow, afkast og skat for en konkret udlejningsbolig med fast eller variabel rente.

Siden er ren HTML uden byggetrin og hostes med GitHub Pages på udlejningsberegner.dk.

- `index.html` er beregneren
- `privatlivspolitik.html` er privatlivspolitikken for ventelisten
- Renterne står i `RENTER` i `index.html` og opdateres i hånden
